- Preview an image of the visible chat window, then copy it, save it as PNG, or share it with a macOS app. The capture keeps the chat’s title and window frame and leaves out the sidebar.
- Remove an agent pane from view while keeping its conversation and private draft. Select its Send to pill to bring it back.
- Start a New Blast or open a single connected agent from the menu bar. Set an optional global shortcut in Settings to bring the composer forward.
